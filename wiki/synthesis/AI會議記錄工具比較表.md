## 選工具決策樹

```
需要台語/客語？
  └─ 是 → [[Meeting Ink]] 或 [[雅婷逐字稿]] 或 [[Tinrec]]（10語言自動識別）

預算為零？
  └─ 是，需要即時轉錄 → [[Easemate AI]]
  └─ 是，需要摘要整理 → [[inFin]] 或 [[CLOVA Note]] + ChatGPT
  └─ 是，需要心智圖/簡報 → [[NotebookLM]]
  └─ 是，可接受按月有限額度 → [[Tinrec]]（100分/月）或 [[Otter.ai]]（300分/月）

主要用線上會議（Meet/Teams/Zoom）？
  └─ Teams / Google Meet → [[SeaMeet]]
  └─ 英文國際會議 → [[Otter.ai]]
  └─ 三平台、多語言 → [[Notta]] 或 [[tl;dv]]
  └─ 需要 AI 對話查詢錄音 → [[Tinrec]]

行動錄音（外出/訪談）？
  └─ 是 → [[Plaud]]（硬體錄音筆）

需要即時翻譯？
  └─ 是 → [[Vurbo.ai]]（但總流程較慢）或 [[Litok]]（即時翻譯）

影音字幕製作（不是會議記錄）？
  └─ 是 → [[RecCloud]] 或 [[Memo AI]]（含心智圖）

只是想用語音輸入文字（不要逐字稿）？
  └─ 繁體中文 → [[Typeless]]（4,000字/週免費）
  └─ 也要 Mac 跨 App → [[Wispr Flow]]（2,000字/週免費）
  └─ 想把口語整理成精煉筆記 → [[AudioPen]]

高頻使用、重視效率？
  └─ → [[Meeting Ink]]（速度+功能最均衡）

低頻、按量計費？
  └─ → [[雅婷逐字稿]] 或 [[Vocol.ai]]（V-point）或 [[cSubtitle]]（NT$323/100分）

日文會議？
  └─ 企業 → [[Smartshoki]]
  └─ 個人 → [[Rimo Voice]]
```

## 注意事項

- 速度數據測試條件為免費版 + 26分鐘英文音檔，付費版或中文音檔結果可能不同
- [[Meeting Ink]] 評測來自其官方部落格，具有立場偏向
- [[Plaud]] Top5 排行由 Plaud 官方撰寫，自評第一，立場偏向
- [[MyEdit]] 文章由 CyberLink 官方撰寫，具商業立場
- [[Tinrec]] 三篇來源均由 Tinrec 官方撰寫，立場偏向明顯
- [[Otter.ai]] 的中文支援目前僅確認簡體中文，繁體仍不建議
- [[cSubtitle]] 94% 準確率為官方自稱數字，缺乏第三方驗證
- AI 摘要可能虛構內容，重要會議記錄需人工驗證
- [[Typeless]]、[[Wispr Flow]]、[[AudioPen]] 定位為「語音輸入法/語音筆記」，非傳統會議記錄工具
