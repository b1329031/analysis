# myVoca

由台灣大哥大與長問科技共同研發的 ASR 語音辨識模型，是國內首款支援中、台、英、客語混合辨識的商用語音 AI。

## 核心規格

| 指標 | 數值 |
|------|------|
| 最高字正確率 | **97%**（政府質詢場景實測 96.70%） |
| 即時辨識延遲 | **< 1 秒** |
| 算力成本節省（對比 Whisper-large-v3） | **88%** |
| 最大高併發支援 | **60 線**（Whisper 同硬體僅 8 線） |
| 支援語言 | 國語、英語、台語、客語 |

## 主要優勢

- **四語混合辨識**：同一段音訊中的中台英客語切換皆可識別，為台灣市場獨特優勢
- **主權 AI**：台灣團隊開發、部署、機房，支援地端部署，符合金融/醫療/政府資安規範
- **PaaS API**：快速 API 串接，支援雲地彈性部署
- **垂直領域微調**：金融、醫療、政府等專業場景可進行模型微調

## 目標客群

1. AI 客服資服業者（降低轉人工率）
2. 多產業垂直解決方案商（提升效率、專業術語優化）
3. AI 賦能軟硬系統商（省去 ASR 自研成本）

## 應用場景

企業商務會議、企業語音客服、醫療與長照記錄、金融與零售服務
